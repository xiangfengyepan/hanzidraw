01

Purpose

hanzidraw exists because of a hard ceiling in its companion project. The Keychron Q1 HE custom firmware in KeychronQMK (users/xiangfeng) bakes its pinyin IME and its stroke dictionary straight into flash. That caps it at 276 characters — about 56 KB of the ~87 KB available, and every additional character is paid for in bytes the keyboard does not have.

The desktop app has no such ceiling. It covers every character that has stroke data (~9,500) plus multi‑syllable words, and it additionally becomes the generator the firmware never had: a subcommand that selects a flash‑budgeted subset and emits a compilable hanzi_data.c.

One data pipeline, two consumers. The desktop app and the keyboard firmware are fed from the same normalised stroke geometry, so the two never drift — and a golden test proves it (§ 9).

Success criteria

  1. Type feng, get a Windows‑like candidate bar, press 1, and 沣 is drawn stroke‑by‑stroke on the canvas at the configured size and colour.
  2. Type beijing, get 北京 as a phrase candidate, and both glyphs draw left‑to‑right on the carriage with correct wrapping.
  3. Editing config.toml changes size / colour / grid / animation speed without restarting the app.
  4. hanzidraw export-firmware --budget-kb 80 --must 沣潘叶祥 writes a compilable hanzi_data.c whose name‑character arrays match the ones in the firmware today.
  5. Installs and runs on both Windows and Linux from one codebase, with no global keyboard hook and no elevated permissions.

Non‑goals

  • Not a system input method. It does not register with Windows TSF or Linux IBus and never inserts text into other applications. (The mouse backend draws into another app, but by synthesizing pointer input, not text.)
  • No global key capture for composition. Composing happens only when the app window has focus — deliberately, because that removes Wayland restrictions, accessibility permissions, and antivirus friction. One narrow, explicit exception: while the mouse backend is actively drawing into another application, a temporary listener is installed solely to catch the abort key, and is removed the moment the draw ends (§ 8).
  • No handwriting recognition — the inverse problem. Input is pinyin only.
  • No traditional/simplified conversion beyond what the source data provides.

03

Architecture

Qt appears only in ui/ and output/canvas.py. Everything else is plain Python and testable without a display server — which is exactly what makes CI on Linux and TDD practical.

Package layout

hanzidraw/
  __init__.py
  config.py          # TOML load/merge/validate, defaults, hot reload signal
  cli.py             # entry points: run | fetch-data | draw | export-firmware
  data/
    sources.py       # URLs, checksums, license/attribution metadata
    fetch.py         # resumable download with progress + integrity check
    build.py         # ETL: raw sources -> SQLite
    store.py         # read API over the SQLite file (the only data consumer)
  ime/
    syllables.py     # the legal-syllable table + pinyin normalisation
    segment.py       # pinyin string -> syllable list (DP, ambiguity handling)
    sources.py       # CandidateSource protocol; CharSource, PhraseSource
    candidates.py    # merge + rank + paginate
    learn.py         # adaptive per-user weights (JSON)
    session.py       # the compose state machine (pure, no Qt, no I/O)
  render/
    glyph.py         # stroke data -> normalised paths in a target box
    animator.py      # time-based reveal timeline -> partial geometry per frame
    sheet.py         # carriage, wrapping, guide grids, undo stack
    theme.py         # named presets -> config overrides
  output/
    base.py          # Backend protocol
    canvas.py        # QPainter into the sheet widget
    mouse.py         # pynput pointer synthesis (port of the firmware engine)
    image.py         # headless PNG/SVG writer
  ui/
    app.py window.py candidatebar.py canvasview.py statusbar.py
  firmware/
    subset.py        # budget-aware character selection
    emit_c.py        # hanzi_data.c / .h emitter, byte-cost accounting
tests/               # pytest; core suites need no display

Module contracts

data.store
The only module that knows SQLite exists. Exposes readings_with_prefix(p, limit), phrases_with_key(key, limit), medians(codepoint), outline(codepoint), char_meta(codepoint). Swapping the storage format touches this file only.
ime.session
feed(key) -> SessionState. Owns the preedit buffer, the candidate page, and the commit queue. No rendering, no file access; candidate lookup arrives through the CandidateSource protocol so tests inject fakes.
render.animator
Given a glyph and a wall‑clock time, returns which strokes are complete and how far along the in‑progress stroke is. Frame‑rate independent and deterministic under an injected clock — so animation is unit tested, not eyeballed.
output.base.Backend
begin_glyph(box), stroke(points), end_glyph(), advance(). Four methods keeps each backend small; the image backend is what lets CI assert on rendered output.
04

Data pipeline

Sources are fetched at first run rather than vendored: the repo stays small and redistribution/licensing stays clean. hanzidraw fetch-data downloads, verifies, and builds; the app refuses to start with a clear message if the database is missing or its schema version is stale.

Sources

SourceProvidesURLLicense
Make Me a Hanzi
graphics.txt		 Per‑character stroke medians (the drawing) and SVG outlines (the typographic shape) raw.githubusercontent.com/skishore/makemeahanzi/master/graphics.txt Arphic Public License / LGPL — attribution in NOTICE
hanziDB
data/hanziDB.csv		 Frequency rank, pinyin, stroke count raw.githubusercontent.com/ruddfawcett/hanziDB.csv/master/data/hanziDB.csv As used by the firmware
CC-CEDICT Words/phrases with numbered pinyin (北京 Bei3 jing1) www.mdbg.net — CC‑CEDICT release CC BY‑SA 4.0
rime-essay

If the optional word‑frequency source is unavailable, phrase ranking falls back to a heuristic over constituent character frequencies. The app must work fully without it.

Coordinate convention

makemeahanzi coordinates live in a 1024‑unit em box with Y pointing up. All geometry is normalised once, in data.build, to a 0 .. 1 box with Y pointing down (screen convention), stored as 16‑bit fixed point. Both the renderer and the firmware exporter then apply their own scale, so the em‑box mapping exists in exactly one place.

Schema

SQLite, with schema_version in a meta table.

char(codepoint INTEGER PRIMARY KEY, freq_rank INTEGER, nstroke INTEGER)
reading(pinyin TEXT, codepoint INTEGER)          -- INDEX on pinyin (prefix scans)
phrase(pinyin_key TEXT, text TEXT, weight REAL)  -- INDEX on pinyin_key
geom(codepoint INTEGER PRIMARY KEY, medians BLOB, outline BLOB)  -- zlib per char
meta(key TEXT PRIMARY KEY, value TEXT)           -- schema_version, source hashes, build date

A character is inserted only if graphics.txt has stroke data for it — the app never offers a candidate it cannot draw. A phrase is inserted only if every constituent character has geometry; phrases failing that are dropped at build time and counted in the build report, so coverage gaps are visible rather than surfacing as a half‑drawn word.

Indexed prefix queries mean no startup load and a small resident footprint. --medians-only at build time omits geom.outline (a much smaller database, and glyph.style = "outline" is then rejected with a clear error). Actual sizes get recorded in the README from a real build — no estimates in shipped docs.

Pinyin normalisation — one function, used everywhere

Toneless; ü and u: become v; CC‑CEDICT tone digits stripped; case folded. Characters with several readings keep every reading, one reading row each.

05

IME engine

Segmentation

beijingdaxue  →  DP over the legal-syllable table  →  bei ' jing ' da ' xue

The segmentation is shown split in the preedit. An explicit apostrophe key forces a boundary, which is the standard resolution for genuine ambiguities (xian vs xi'an, nanan vs nan'an). Where no apostrophe is given, the segmenter prefers the fewest syllables, then longest‑first.

When an input has more than one valid segmentation, candidates are drawn from the top two segmentations and merged — the preferred one first — rather than silently discarding the alternative.

Candidate ranking

In order:

  1. Exact‑key phrases
  2. Longest‑prefix phrases
  3. Single characters by frequency rank

…then deduplicated. ime.learn promotes what you have actually picked (a small JSON of counts and recency in the user data dir), which is what makes it feel like a real IME rather than a lookup table. It is config‑gated by ime.learn and resettable.

06

Rendering

Two styles come out of the same data.

brush
Medians drawn as round‑capped polylines. Matches the firmware's look, and is the only style the mouse backend can produce — a pointer can only trace a path.
outline
The real typographic shape: the SVG outline is used as a clip and revealed by a thick pen travelling along the median, so a stroke grows with its true contour.

Animation

Animation is time‑based — per‑stroke duration, inter‑stroke gap, easing — and therefore frame‑rate independent. render.animator is asked “given this glyph and this wall‑clock time, which strokes are done and how far along is the current one?”, which is why it can be unit tested under an injected clock instead of eyeballed.

Canvas modes

  • single adds replay, step‑by‑stroke, and optional stroke‑order numbers.
  • sheet keeps confirmed glyphs, advances the carriage, wraps lines, and can draw a 田 or 米 guide grid.

canvas.columns sets where a line wraps and canvas.advance sets the spacing, so the sheet is columns × advance × glyph.size_px wide. The view scrolls when the window is narrower than that, and never reflows on resize — so a written sheet keeps its layout.

07

Configuration

TOML at ~/.config/hanzidraw/config.toml (Linux) or %APPDATA%\hanzidraw\config.toml (Windows), hot‑reloaded on save via a file watcher, with validation errors surfaced in the app's status bar instead of crashing. Unknown keys are a warning, not a failure. --config PATH overrides the location.

This block is the answer to “how do I change the size and the colour?” — every knob the app has, in one file, with no restart.

[glyph]
style = "brush"               # brush | outline
size_px = 240
stroke_width_px = 14
color = "#111111"             # or ["#c0392b", "#f39c12"] for a gradient
outline_color = "#cccccc"
show_pending_outline = true   # ghost of the full character while drawing
stroke_numbers = false

[glyph.animation]
enabled = true
stroke_ms = 380
gap_ms = 90
easing = "ease_out"           # linear | ease_in | ease_out | ease_in_out

[canvas]
mode = "sheet"                # sheet | single   (F2 toggles)
background = "#fdfdf7"
grid = "tian"                 # none | tian | mi | cross
grid_color = "#e5ded0"
columns = 6
advance = 1.15                # multiple of size_px
wrap = true
always_on_top = false

[ime]
page_size = 9
phrases = true
learn = true
max_candidates = 200

[output]
backend = "canvas"            # canvas | mouse | image

[output.mouse]
scale = 1.0
step_delay_ms = 4
button = "left"
clamp_to_screen = true

[output.image]
dir = "~/Pictures/hanzidraw"
format = "png"                # png | svg

[theme]
preset = "ink"                 # ink | neon | chalk | none (none = use values above)

theme.preset supplies defaults that explicit keys above override, so a preset never silently discards a setting you wrote.

08

Output backends

canvas
QPainter into the sheet widget. Always available.
mouse
pynput pointer synthesis: absolute moves with the button held for the duration of a stroke and released between strokes, mirroring the firmware's draw engine. Screen‑bounds clamping, a configurable step delay for applications that drop fast input, and an abort path that works even though our window is unfocused during the draw — because a runaway synthetic pointer is hostile. It refuses to start when the focused window is our own.
image
Headless renderer behind hanzidraw draw 沣潘叶祥 -o name.svg. This is also the backend CI uses to assert on rendered geometry.

The mouse backend's abort path is threefold

GuardTrips onLifetime
Temporary pynput key listenerCtrl+. while another app has focusInstalled when the draw starts, removed the moment it ends
Physical‑movement detectionYou move the real mouseFor the duration of the draw
Hard per‑glyph time limitWall clock, unconditionallyStops the draw and releases the button

This is the one place the no‑global‑hook rule bends, and it bends only for the abort key, only while a synthetic pointer is moving, and it is off by default (output.backend = "canvas").

09

Firmware exporter

hanzidraw export-firmware --budget-kb 80 --must 沣潘叶祥 --per-initial 12 \
    -o ~/KeychronQMK/users/xiangfeng/src/ime/hanzi_data.c

Selection: must‑have characters first (so 沣/潘/叶/祥 remain candidate 1 for their syllable), then by hanziDB frequency rank, optionally capped per pinyin initial, stopping at the byte budget.

Emission matches the firmware's existing format exactly — x[], y[], len[], hanzi_table[], hanzi_count — with per‑character byte cost measured from the emitted arrays rather than assumed, and a summary printed: characters selected, total KB, headroom.

Golden test. Regenerating with the current parameters must reproduce the existing arrays for the four name characters byte‑for‑byte. That test is the proof the em‑box transform was ported correctly, and it fails loudly if either side drifts.

10

Installation

One codebase, both platforms. uv tool install hanzidraw or pipx install .; hanzidraw launches the app, hanzidraw fetch-data builds the database with a progress bar and resumable downloads. An optional PyInstaller spec produces a Windows .exe for a Python‑free install. PySide6 is LGPL, which suits both distribution paths.

Risks and mitigations

RiskMitigation
Pinyin ambiguity (xi'an) segmented wronglyApostrophe key, both branches offered as candidates, dedicated test suite
Phrase ranking is mediocre without a word‑frequency sourceCharacter‑frequency fallback plus ime.learn; the optional source improves it rather than gating it
Outline blobs dominate database size--medians-only build flag; outline style then errors clearly
Synthetic pointer input misbehaving in the mouse backendBounds clamping, abort hotkey, configurable pacing, off by default
Source data or URLs changing upstreamChecksums recorded in meta; fetch-data reports a mismatch instead of building a corrupt database
Scope creep toward a real system IMEExplicit non‑goal; the CandidateSource seam is where any future work goes
